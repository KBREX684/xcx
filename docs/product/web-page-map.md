# Web 页面地图

## 1. 文档目标

本文件用于固化 `智能代理指挥台` 当前 Web 控制台的页面结构，并为后续 P3 优化与小程序延展提供统一参考。

它是以下事项的统一口径：

- 当前已经实现的 Web 路由范围
- 页面之间的层级关系与导航方式
- 下一阶段仍需补足或深化的页面方向

## 2. P2 当前页面总览

P2 已经把 P1 的单页 cockpit，扩展为一套可持续增长的中文控制台。

## 4. 页面组织原则

- 全局页通过左侧导航切换：`工作台 / 项目 / 审批 / 执行代理 / 流程模板 / 证明书中心 / 接入配置`
- 项目内页通过面包屑和上下文链接下钻，不再额外复制全局导航
- 所有页面统一为全中文文案，并支持 `system / light / dark` 三态主题
- 数据密集页优先采用“舒适表格 + 卡片混合”的方式，不做压抑式纯后台风格
- 任务、执行记录、交付产物全部从项目 cockpit 可回溯，避免信息断层

## 5. P3 阶段待深化方向

P2 已完成结构补齐，P3 主要聚焦体验深化，而不是继续堆新页面。

### 5.1 重点深化项

| 方向 | 说明 |
| --- | --- |
| 首页 Hero 与项目 cockpit 视觉深化 | 继续基于 `huashu-design` 打磨首屏冲击力与品牌识别度 |
| 数据密集页舒适度优化 | 基于 `ui-ux-pro-max` 继续微调排版、间距、焦点态与低疲劳色阶 |
| 证明书详情与导出页 | 从列表摘要升级为可预览、可导出、可验证的详情视图 |
| 成员与权限页 | 在完整鉴权体系落地后补充成员、角色与权限配置页面 |
| 通知与提醒中心 | 当通知通道进入真实接入时，再补独立的消息/提醒视图 |

### 5.2 当前仍未进入 Web 范围的事项

- 微信小程序端代码
- 真实 OpenAPI 执行器接入页
- MCP Relay 可视化管理页
- 完整登录、权限与审计后台
